## 设计原则

1. **零后端依赖**:所有 stories 通过 `HermesApiMockProvider` 注入内存版 HermesApi
2. **真实交互**:每个 story 都可点击、可操作(用 `@storybook/test` 的 `play` 函数)
3. **可访问性**:集成 `@storybook/addon-a11y` 自动检测 ARIA 问题
4. **TypeScript 严格模式**:所有 props 通过 `Meta<typeof Component>` 推断,argTypes 自动生成

## 常见使用

```tsx
import { SkillTree } from '@/components/hermes/SkillTree';

<SkillTree
  skills={data}
  onSelectSkill={(s) => console.log(s)}
  defaultCollapseArchived
/>
```
